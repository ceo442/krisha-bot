# Бот новых объявлений krisha.kz → Telegram

Работает бесплатно на GitHub Actions: каждые ~10 минут запускается сервер GitHub, бот 9 минут подряд проверяет поиски (раз в ~90 секунд) и отвечает на команды, потом сохраняет состояние в папку `data/`.

## Команды в Telegram
- `/add Название | ссылка с krisha.kz` — добавить поиск (настрой фильтры на сайте, скопируй ссылку)
- `/list` — список поисков
- `/del Название` — удалить поиск
- `/all` — прислать все объявления, которые сейчас есть по поискам
- `/check` — проверить прямо сейчас

При добавлении поиска бот запоминает текущие объявления и дальше присылает только новые.
Платные «горячие» карточки бот пропускает. Изредка может прийти старое объявление, которое владелец «поднял» в ТОП.

## Настройка (один раз)
1. Секреты репозитория (Settings → Secrets and variables → Actions):
   - `TELEGRAM_TOKEN` — токен от @BotFather
   - `CHAT_ID` — необязательно: если не задан, владельцем станет тот, кто первым напишет боту
2. Actions → krisha-bot → Run workflow (первый запуск вручную).

## Локальный запуск (необязательно)
`TELEGRAM_TOKEN=... python3 bot.py` — работает постоянно, пока открыт терминал.

## Файлы
- `bot.py` — сам бот (только стандартный Python, без библиотек)
- `.github/workflows/bot.yml` — расписание запуска на GitHub
- `data/` — поиски и уже отправленные объявления (обновляется ботом)

## Несколько получателей
`CHAT_ID` может содержать несколько чатов через запятую (личные чаты и группы), например `73422248,-1001234567890`.
Проще всего — добавить бота в группу Telegram и указать её ID: объявления увидят все участники группы.
